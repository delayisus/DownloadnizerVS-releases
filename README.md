# DownloadnizerVS: versiones

Aquí se publican los instaladores de **DownloadnizerVS**, un programa para Windows
que descarga vídeo o audio a la máxima calidad (YouTube, X y otras webs).

- **Instalar:** descarga el `DownloadnizerVS-Setup-x.y.z.exe` de la [última versión](../../releases/latest).
  Windows puede avisar «Windows protegió su PC»: pulsa «Más información» y «Ejecutar de todas formas».
- **Actualizar:** no hace falta venir aquí. La app avisa sola cuando hay una versión nueva
  y se actualiza con un clic.

El código del programa está en un repositorio privado.
